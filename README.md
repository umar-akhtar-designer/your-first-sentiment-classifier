# 🎬 Your First Sentiment Classifier

My first hands-on machine learning project, where I built a model to understand movie reviews and predict whether people liked or disliked a movie.

This project is part of my **Week 1 milestone in the SkillMe Machine Learning Virtual Internship**.

## About the Project

I worked with 50,000 IMDB movie reviews and used Python to build a sentiment classifier.

The idea was to teach a machine learning model how to recognize positive and negative opinions from text. Along the way, I learned how raw text can be cleaned, converted into numbers, and used to train a model.

## Dataset

I used the IMDB Dataset of 50K Movie Reviews from Kaggle.

[Get the dataset here](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

The CSV file is not included in this repository because it exceeds GitHub's upload limit. To run the notebook, download the dataset and upload it to your Google Colab session.

## What I Worked On

- Explored the movie reviews using Pandas
- Cleaned the text by removing HTML tags and punctuation
- Converted reviews into numerical features using Bag-of-Words
- Trained a Logistic Regression model
- Evaluated the model on a separate test set
- Tried the model on my own sentences, including tricky examples

## Tools and Libraries

Python · Pandas · Matplotlib · Scikit-learn

## What I Learned

This project helped me understand the basic workflow of text classification, from preparing a dataset to training and testing a model.

I also learned why it is important to fit the text vectorizer only on the training data and keep the test data separate.
